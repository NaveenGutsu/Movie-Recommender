# movie recommender using knn

a beginner-friendly movie recommendation tool built in python using the k-nearest neighbors algorithm.

## about the project
this program works like a smart movie buddy. it plots movies on a grid based on genres like action and romance. when you enter your own preference scores, the model finds the closest matches using distance calculations and suggests the best movies for you.

# features
- uses scikit-learn nearest neighbors for fast distance calculation
- simple pandas dataframe setup
- easy to add more movies and genre categories

# requirements
install the required libraries:
pip install pandas scikit-learn

# how to run
1. clone the repository:
   git clone https://github.com/your-username/movie-recommender-knn.git
2. navigate to the folder:
   cd movie-recommender-knn
3. run the script:
   python recommender.py
